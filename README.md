# Rebuild Small Business Site

A free skill and plugin: paste a small-business URL and a brief, get a rebuilt and improved marketing site. Booking and checkout stay on the system that already takes money.

This repo is the plugin and a one-plugin marketplace for Grok and Claude/Cursor.

**Status:** design spec is in [docs/superpowers/specs/2026-08-15-rebuild-small-business-site-design.md](docs/superpowers/specs/2026-08-15-rebuild-small-business-site-design.md). The skill is not implemented yet.
