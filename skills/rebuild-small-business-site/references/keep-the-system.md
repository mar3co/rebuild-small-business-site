# Keep the system that takes money

The marketing site sells the visit. It does not become the register.

## Recognize it

| Signal on the live site | System to keep |
| --- | --- |
| `mindbodyonline.com`, HealCode, Branded Web iframe | Mindbody — product URLs + official schedule widget |
| `myshopify.com`, `/cart`, Shopify checkout | Shopify checkout. Rebuild marketing pages only if asked |
| `squareup.com`, Square Online, `square.site` | Square |
| Jane App, `jane.app` | Jane |
| Vagaro, `vagaro.com` | Vagaro |
| Calendly / Acuity / Setmore | That scheduler |
| “Call to book” / SMS only, no cart | Phone/SMS is the system. `tel:` / `sms:` from `site` |

If two systems appear, keep both and say so. Do not merge them into a new form.

## What “keep” means

- Every Book / Buy / Sign up control is a real URL or official embed from that system
- Displayed prices are copy; the system is what they can actually buy
- Do not build a custom checkout, calendar, login, or “request a time” form that was not already on the site
- Official widgets (schedule iframes) beat a rebuilt calendar

## Leave it when leaving would break the business

Shopify storefront, Square Online store, a native booking product they already run as the site — stay. Rebuild a marketing layer around it only if the brief asks.
