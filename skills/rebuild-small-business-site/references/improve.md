# Improve, do not clone

The old sitemap is evidence, not the spec. Propose a tighter IA and current defaults even if the old site never had them. Then build.

New **pages** are allowed. New **facts** are not.

Copy on a new page must come from how they already talk (live site, brief, listed reviews). Otherwise the page stays client-open or it does not ship.

## Defaults to consider (drop any that do not fit)

- **Start** — how to begin, split new vs returning when that is how they already work
- **Visit** — NAP, hours, map. Not a 2015 “Contact” form unless they already take leads that way
- **FAQ** — from the live site or the brief
- **Reviews** — only with real quotes or sourced aggregates
- LocalBusiness JSON-LD
- Favicon and share cards from **their** mark
- Mobile-first nav, one primary CTA
- Redirects from old paths so the improved IA does not 404 bookmarks

Primary nav is a few jobs (Start / services / pricing / Visit), not every WordPress page. The rest can live in the footer.

## Design

Use frontend-design. Pull the mark from their logo. Use their photography. Match type to the room, not to a “more feminine / more premium” default. Proof is real ratings, not invented testimonials.

## Client-open

Roster names, unpublished hours, photo rights, DNS holder, booking-widget access — leave them open. Do not fill the gap.
